# E-Commerce Sales Dashboard

## Overview
This Power BI dashboard provides insights into e-commerce sales performance, profitability, customer behavior, and payment preferences. It enables users to analyze sales trends and identify key business opportunities.

## Key Metrics
- Total Profit: 37K
- Total Sales Amount: 438K
- Total Quantity Sold: 5.6K
- Average Order Value: 120.9

## Features
- Category-wise sales analysis
- State-wise sales performance
- Monthly profit tracking
- Top customer analysis
- Payment mode distribution
- Sub-category sales analysis
- Quarter and month filtering

## Tools Used
- Power BI
- DAX
- Data Modeling
- Data Visualization

## Business Insights
- Clothing contributed the highest share of sales.
- Maharashtra generated the highest sales among all states.
- Cash on Delivery (COD) was the most preferred payment method.
- Monthly profit trends highlight seasonal variations in performance.
