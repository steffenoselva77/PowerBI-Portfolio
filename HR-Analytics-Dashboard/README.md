# HR Analytics Dashboard

<img src="HR Analytics Dashboard.png" width="1000">

## Overview
This Power BI dashboard provides comprehensive workforce analytics by examining employee attrition, demographics, compensation patterns, and job-role performance. The dashboard helps identify factors influencing employee turnover and supports data-driven HR decision-making.

## Key Metrics
- Total Employees: 1.48K
- Attrition Count: 238
- Attrition Rate: 16%
- Average Age: 36.92 Years
- Average Salary: 6.50K
- Average Years at Company: 7.01

## Features
- Employee attrition analysis by education field
- Gender-wise attrition distribution
- Attrition analysis across age groups
- Salary slab analysis
- Job role performance analysis
- Department-level filtering
- Interactive workforce insights

## Tools Used
- Power BI
- DAX
- Data Modeling
- Data Visualization

## Business Insights
- Employees aged 26–35 experienced the highest attrition.
- Most attrition occurred within lower salary ranges.
- Attrition varied significantly across job roles.
- Education background influenced employee turnover patterns.
- Workforce demographics provided valuable retention insights.
